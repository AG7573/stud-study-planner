Study Planner App

- A simple and responsive study planner application which helps users to keep track of deadlines, and complete subjects and its tasks according to the schedule generated by the planner.

Features

- Generates a schedule with respect to the dates, subjects and tasks inserted by the user.
- Displays subject list, task list.
- Allows editing of tasks and subjects.
- Responsive design for desktop and mobile devices.
- Passwords are hashed, and every route checks that the data belongs to the logged-in user.

Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python(Flask)
- Database: MySQL
- Tools: Git, Github, VS Code

Getting Started

- Follow these steps to run the project locally

Prerequisites

- A web browser
- A code editor such as VSCode

Installation

1. Clone the repository: https://github.com/AG7573/stud-study-planner.git
2. Navigate to the project directory: cd stud-study-planner
3. Open the project in VSCode
4. Run app.py in your browser and use a local development server.

Usage 
 
1. Launch the application.
2. Signup with a valid email and name, password.
3. Add a subject with the exam date or any deadline.
4. Add a few tasks as in chapters or unit names of the subject with final dates.
5. Generate a schedule using the built-in function.
